# EVIM Content Importer

A WordPress plugin that imports full content from external URLs, removes common ad blocks, downloads images into your media library, and saves the result as a draft post.

## Features
- Fetches and imports full HTML content from any URL.
- Removes common ad containers and non-content elements (scripts, iframes, etc.).
- Downloads images into WordPress and rewrites image URLs.
- Creates draft posts ready for review.

## Usage
1. Upload the `evim-content-importer` folder to your WordPress `wp-content/plugins` directory.
2. Activate the plugin.
3. Go to **Tools → EVIM Content Importer**.
4. Paste a URL and click **Import as Draft**.

> Ensure you have permission to reuse content from the source website.
